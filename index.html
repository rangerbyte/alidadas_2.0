¿Cómo funciona el cálculo?

Los vigilantes de incendios, situados en puestos fijos a gran altitud, visualizan una columna de humo y toman el **rumbo acimut** (en grados de 0 a 360, medido en el sentido de las agujas del reloj, donde el Norte es 0º, el Este es 90º, el Sur es 180º y el Oeste es 270º) utilizando un visor óptico llamado **alidada**.

Al registrar al menos **dos rumbos** procedentes de dos torres de coordenadas conocidas, el sistema traza círculos máximos sobre la esfera terrestre para calcular el punto exacto donde se intersectan las visuales.

Soporte de Archivos Excel

La aplicación es compatible con el archivo de inventario forestal estatal Copia de Puestos_vigilancia_2019_ALIDADAS.xlsx u otros personalizados.

Columnas requeridas (en español o inglés):
• Nombre, Puesto, Vigilancia o ID
• Latitud o Coordenada Y (UTM Norte)
• Longitud o Coordenada X (UTM Este)
• Huso (Opcional, por defecto 30N)

El sistema detecta automáticamente si las coordenadas están codificadas en UTM (p.ej. 4452100 metros) o en grados decimales (p.ej. 40.6789), realizando las conversiones geométricas complejas de manera interna.

Haz clic en cualquier parte del mapa para añadir un nuevo puesto directamente.
